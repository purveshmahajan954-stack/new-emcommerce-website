Create a new page called "Wellness Score" (add it to the main navigation) with the following features:

1. DAILY INPUT FORM
Create a simple form where a logged-in user can enter, once per day:
- Calories intake (number input, in kcal)
- Water intake (number input, in glasses or ml — use glasses of 250ml)
- Hours slept (number input, decimal allowed e.g. 7.5)
- Steps taken (number input)

Include a "Submit Today's Log" button. If the user has already submitted for today, show their entered values with an "Edit" option instead of a blank form.

2. SCORE CALCULATION LOGIC
Calculate a daily wellness score out of 100, based on how close each metric is to its ideal target. Each metric contributes 25 points max:

- Calories: target = 2000 kcal. Score = 25 - (|entered - 2000| / 2000 * 25), capped between 0-25
- Water: target = 8 glasses (2000ml). Score = min(entered/8, 1) * 25, capped at 25
- Sleep: target = 8 hours. Score = 25 - (|entered - 8| / 8 * 25), capped between 0-25
- Steps: target = 10,000 steps. Score = min(entered/10000, 1) * 25, capped at 25

Total Daily Score = sum of all four (rounded to nearest whole number, 0-100).

Store each day's score with date and user info in the database.

3. DASHBOARD / LEADERBOARD
Create a dashboard section on the same page showing:
- A leaderboard table/list of all users ranked by their CURRENT MONTH cumulative score (sum or average of daily scores for the month)
- Display: Rank, Full Name, Total/Average Score
- Highlight the logged-in user's own row (e.g. different background color)
- Show top 3 with a badge/icon (gold, silver, bronze style, matching the earthy brown/beige/green theme)
- Below the leaderboard, show the logged-in user's own stats: today's score, this month's average score, and a simple line/bar chart of their last 7 days' scores

4. MONTHLY WINNER LOGIC
- At the end of each month, the user with the highest cumulative/average score for that month should be flagged as "Winner"
- Store a monthly_winners table/record with user, month, and score
- Display a small "Last Month's Winner" card on the dashboard (name + score + a small trophy icon)
- Winner should be eligible for a discount coupon — for now, just log/flag this in the backend (e.g. winner.coupon_eligible = true); no need to build coupon generation/email system yet unless specified

5. STYLING
- Match the existing earthy beige/green/brown theme, serif headings, same fonts and spacing as the rest of the site
- Mobile responsive — form and leaderboard should stack cleanly on smaller screens
- Keep the tone premium and clean, not gamified/childish — use subtle icons, not flashy badges
